[How's My Code](http://howsmycode.r09.railsrumble.com/) is a Git-based lightweight code review app. You don't get much of an idea from the front page, but sign up and log in and you'll see this is a well designed and useful tool. If you work in a remote team environment and use Git at all, check it out. Basically you can comment on any commits made on git repositories of your choice. via Rails Insider.
